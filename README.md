# نظام الحضور والإجازات — MATCO

موقع HTML بيشتغل على المتصفح، والبيانات محفوظة في Supabase.

## محتويات المشروع
| الملف / الفولدر | الوظيفة |
|---|---|
| `index.html` | الصفحة الرئيسية |
| `css/style.css` | التصميم والألوان |
| `js/app.js` | تشغيل الموقع |
| `js/config.js` | **رابط قاعدة البيانات والمفتاح العام — ده الملف الوحيد اللي بتعدّله** |
| `lib/` | مكتبات جاهزة (Supabase و Excel) — ما تتعدلش |
| `database/` | أكواد قاعدة البيانات (بتتشغّل مرة واحدة في Supabase ← SQL Editor) |

## ملاحظات
- في `js/config.js` يتحط **المفتاح العام (publishable / anon)** بس — **ممنوع** المفتاح السري.
- المستخدمين بيتعملوا من Supabase ← Authentication ← Users، بإيميل شكله `اسم-المستخدم@matco.app`.
- الاستضافة: Cloudflare Pages مربوط بالمشروع ده — أي تعديل بيتنشر تلقائيًا.
